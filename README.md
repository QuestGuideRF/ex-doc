# ExDoc

ExDoc — генератор документации для Elixir-проектов. Он собирает API-справку, дополнительные страницы и гайды, а затем выпускает готовую HTML- или EPUB-документацию, которую можно публиковать локально или на HexDocs.

## ✨ Особенности
- Генерирует HTML- и EPUB-документацию из Elixir-модулей и комментариев.
- Поддерживает `mix docs` и запуск через escript из командной строки.
- Умеет включать дополнительные страницы и гайды помимо API-справки.
- Содержит встроенный поиск, навигацию по версиям и offline-friendly HTML.
- Позволяет настраивать логотип, группировку модулей и оформление документации.

## 🚀 Быстрый старт
### Использование в своём Elixir-проекте
Добавьте зависимость в `mix.exs`:

```elixir
def deps do
  [
    {:ex_doc, "~> 0.21", only: :dev, runtime: false}
  ]
end
```

После этого установите зависимости и сгенерируйте документацию:

```bash
mix deps.get
mix docs
```

### Разработка самого ExDoc
Для локальной работы с этим репозиторием:

```bash
mix setup
mix build
```

Команда `mix setup` подтянет Elixir-зависимости и установит frontend-ассеты через `npm install`, а `mix build` соберёт ассеты, перекомпилирует ExDoc и заново создаст документацию.

### CLI-режим через escript
ExDoc можно установить как escript:

```bash
mix escript.install hex ex_doc
```

## 📁 Структура проекта
- `lib/ex_doc.ex` — основная логика генерации документации.
- `lib/mix/tasks/docs.ex` — реализация команды `mix docs`.
- `lib/ex_doc/formatter/html` — HTML-форматтер и шаблоны страниц.
- `lib/ex_doc/formatter/epub` — EPUB-форматтер и его шаблоны.
- `assets` — frontend-ассеты и сборка клиентской части документации.
- `formatters` — собранные шаблоны и данные форматтеров.
- `test` — тесты и проверки поведения генератора.

## 🛠 Использование
### Генерация документации через Mix
```bash
mix docs
```

### Генерация документации через CLI
```bash
ex_doc "PROJECT_NAME" "PROJECT_VERSION" path/to/project/ebin -m "PROJECT_MODULE"
```

### Что получается на выходе
После выполнения `mix docs` ExDoc собирает документацию по модулям, функциям и дополнительным страницам, добавляет поиск, ссылки на исходный код и готовит статический набор файлов документации.

## Разработка ресурсов ExDoc

Исходники CSS и JavaScript находятся в `assets/`. Webpack и Less формируют готовые файлы в `formatters/html/dist/` и `formatters/epub/dist/`. В проекте предусмотрены команды `npm run build`, `npm run lint`, `npm run test` и `npm run watch`. Для сборки ресурсов и последующей перекомпиляции Elixir используйте `mix build` из корня проекта.

Markdown-файлы в `test/fixtures/` используются тестами форматтеров HTML и EPUB как входные страницы. Они проверяют обработку заголовков, ссылок и дополнительных документов.

Подпись относится к текущей версии проекта.
